⚡ 간편 상품 추가 상품 추가 전용 · 한 줄 = 상품 1개
상품명 / 카테고리 / 브랜드 / 원가 / 카드원가 / 판매가 / 현재 재고를 적으세요. 엑셀에서 복사한 표를 붙여넣기(Ctrl+V) 하면 여러 줄이 한 번에 채워집니다. Enter·↑↓←→ 로 칸 이동, 마지막 줄에서 Enter 를 누르면 줄이 늘어납니다.
마우스로 끌거나 Shift+클릭 / Shift+방향키로 여러 칸을 고른 뒤 Ctrl+C · Ctrl+X · Ctrl+V · Delete 를 쓸 수 있고, 값 하나를 여러 칸에 붙여넣으면 모두 같은 값이 들어갑니다. 줄 번호를 누르면 줄 전체가 선택되고, 선택 범위 오른쪽 아래 파란 점을 아래로 끌면 같은 값으로 채워집니다. 잘못했으면 Ctrl+Z. 카드원가를 비워두면 원가·판매가로 자동 계산됩니다. 브랜드를 비워두면 상품명에서 자동으로 찾고, 카테고리는 이미 있는 이름만 가능합니다.
